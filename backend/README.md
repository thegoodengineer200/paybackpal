PayBackPal

PayBackPal is a credit-card repayment and borrower tracking backend built with Spring Boot, PostgreSQL, JWT authentication, Flyway migration and Testcontainers.

Phase 1:

- User registration
- Login with JWT
- Protected APIs
- Credit card management
- Borrower/contact management
- Personal transaction logging
- Borrowed transaction logging
- Percentage split calculation
- Equal split calculation
- Owner share calculation
- Repayment status lifecycle
- Dashboard and summary APIs
- Unit and integration tests for above features
